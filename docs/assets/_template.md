# 에셋 이름 — 가이드

## 개요

에셋의 목적과 가장 적합한 사용 사례를 설명합니다.

## 설치

1. 다운로드한 파일의 압축을 해제합니다.
2. 사용하는 엔진 또는 제작 도구에 맞는 폴더를 가져옵니다.
3. 포함된 데모 또는 예제 파일에서 권장 설정을 확인합니다.

## 파일 구성

- `/Source` — 편집 가능한 원본
- `/Engine` — 엔진별 패키지
- `/Demo` — 예제 장면 또는 프리셋
- `/Documentation` — 추가 문서

## 권장 사용 순서

1. 기본 구성 요소로 장면 또는 시스템의 큰 구조를 만듭니다.
2. 변형 요소를 추가해 반복감을 줄입니다.
3. 프로젝트 성능 목표에 맞게 품질과 최적화 설정을 조정합니다.

## 지원

지원 범위, 알려진 제한 사항, 문의 경로를 작성합니다.
