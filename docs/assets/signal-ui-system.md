# Signal UI System — 에셋 가이드

## 개요

전술 및 SF 게임을 위한 HUD, 인벤토리, 미션 로그와 설정 화면을 하나의 규칙으로 관리하는 인터페이스 키트입니다.

## 권장 사용 순서

1. Figma 원본에서 색상과 타이포그래피 토큰을 프로젝트에 맞춥니다.
2. 화면 템플릿과 HUD 컴포넌트를 필요한 흐름에 맞게 조합합니다.
3. 벡터 또는 PNG 에셋을 대상 엔진으로 내보냅니다.
4. 포커스, 선택, 비활성 상태가 실제 입력 환경에서 구분되는지 확인합니다.

## 포함 항목

화면 템플릿 28종, HUD 컴포넌트 76종, 아이콘 180종, Figma 원본과 스타일 가이드가 포함됩니다.
