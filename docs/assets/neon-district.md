# Neon District — 에셋 가이드

## 개요

Neon District는 골목, 상점, 옥상과 네온 사인을 공통 그리드 위에서 조립하는 모듈형 사이버펑크 환경 키트입니다.

## 설치

FBX 또는 OBJ 모델과 PNG 텍스처를 프로젝트로 가져온 뒤 Unity 또는 Unreal용 데모 씬을 기준으로 머티리얼을 연결합니다.

## 권장 사용 순서

1. 건축 모듈로 도로와 건물 실루엣을 구성합니다.
2. 상점 외벽과 옥상 구조물로 구역별 차이를 만듭니다.
3. 네온 사인과 거리 소품으로 시선과 동선을 정리합니다.
4. 2K 또는 4K PBR 텍스처를 성능 목표에 맞게 선택합니다.

## 포함 항목

건축 모듈 64종, 네온 사인 42종, 거리 소품 38종, 데모 씬과 라이트 프리셋이 포함됩니다.
