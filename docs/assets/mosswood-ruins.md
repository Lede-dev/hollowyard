# Mosswood Ruins — 에셋 가이드

## 개요

Mosswood Ruins는 돌 구조물과 식생을 조합해 작은 던전부터 넓은 야외 유적까지 만드는 스타일라이즈드 환경 세트입니다.

## 권장 사용 순서

1. 벽, 아치, 계단으로 주요 동선을 구성합니다.
2. 파편과 바닥 데칼로 구조물의 손상 정도를 조절합니다.
3. 식생 에셋을 겹쳐 시간감과 구역별 밀도를 만듭니다.
4. 주간·야간 데모 씬을 조명 기준으로 활용합니다.

## 기술 정보

FBX, OBJ, PNG 형식과 2K PBR 텍스처를 제공하며 Unity와 Unreal Engine을 지원합니다.
