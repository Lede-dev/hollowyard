# Impact SFX Essentials — 에셋 가이드

## 개요

타격, 폭발, 금속, 파편과 에너지 계열 효과음을 완성음과 개별 레이어로 제공하는 사운드 라이브러리입니다.

## 권장 사용 순서

1. 메타데이터 시트에서 카테고리와 강도로 필요한 소리를 찾습니다.
2. 빠른 적용에는 완성 효과음을 사용합니다.
3. 고유한 연출에는 개별 레이어를 조합합니다.
4. 게임 내 동시 재생 수와 라우드니스 기준에 맞게 정리합니다.

## 기술 정보

모든 파일은 24-bit / 96kHz WAV 형식이며 상업적 사용을 지원합니다.
